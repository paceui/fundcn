# Fundcn

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![X (formerly Twitter) Follow](https://img.shields.io/twitter/follow/withden_)](https://x.com/withden_)

Beautiful, copy-paste funding and sponsorship components for your React apps, built on [shadcn/ui](https://ui.shadcn.com).

## Install

Generate your installation command directly from the builder.

## Use

```tsx
import { ShowcaseStage } from "@/components/sponsor/showcase/stage"
import { PricingCards } from "@/components/sponsor/pricing/cards"

export function SponsorsPage() {
  return (
    <>
      <ShowcaseStage />
      <PricingCards />
    </>
  )
}
```
